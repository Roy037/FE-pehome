# Bundled company logos

`CompanyLogo` loads `/logos/<slug>.webp` (slug = company name without accents, lowercase, dashes) when a company has no uploaded logo. Files are square, 256×256 WebP, shown edge to edge (originals are kept in `design-source/logos`).

## Sources (added 2026-09-30)
